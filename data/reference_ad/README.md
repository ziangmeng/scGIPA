# Synthetic four-state reference inputs

These files contain no real participants, clinical measurements, genotypes or
association results. They are generated by grs_vae.reference_data with seed 7.

There are 24 simulated donors (six per YA, HA, PCI and AD state), three cell
types, 12 cells per donor and cell type, 64 genes and 18 nonzero gene–cell
prior coordinates. Per state, three donors are assigned to training, one to
validation and two to testing. The resulting dataset has 864 cells.

The signed prior matrix is indexed by cell type and gene. Its evidence table
is marked synthetic. Training targets and donor partitions are in metadata.csv.
The loader matches all files by identifiers.

Regeneration with --regenerate writes a new dataset below the chosen output
directory and does not replace these version-controlled reference inputs.
